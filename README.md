# 口型跟读 (lesson viewer)

A static page that shows lesson sentences on the left and the CHIMERA vocal tract simulator on the right.
CHIMERA Vocal Synth by Jameson Hodge, MIT License (see LICENSE): https://github.com/jamesondh/chimera-vocal-synth
The compiled web app files here come from https://chimera.audio; one script (`assets/mount-*.js`) was lightly modified (word label case). `lesson.html` is the added lesson page.
